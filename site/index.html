02 / Small tool. Explicit contract.

From usage to a release gate.

[01] CAPTURE

Bring usage, not prompts.

Record each model call's final token counts. Include retries and tool loops. Add task outcomes from your own evaluator.

[02] ACCOUNT

Use your actual rates.

Separate uncached input, cache reads, cache writes, and output. Supply an explicit price file. Unknown prices fail validation.

[03] COMPARE

Keep failures in the bill.

Compare total token spend per successful task. Fail CI if costs rise beyond your threshold or a previously passing task fails.

04 / Provider compatibility

One format. Different providers.

AUTOMATIC NORMALIZATION

OpenAI & Anthropic

Import final OpenAI Responses or Anthropic Messages JSON. Their cache accounting differs; the adapters handle those supported shapes.

COMMON JSONL

Other model APIs

Use Gemini, Bedrock, or another provider by mapping usage into the common format and supplying its applicable token prices.

NOT YET AUTOMATIC

Native agent logs

Claude Code and Codex session logs need their own importers. An app log is not the same thing as a final model API response.

Check the compatibility guide ↗

Honest boundaries. TraceFrugal estimates token cost. It does not compress prompts, grade answers, reconcile invoices, or establish statistical significance.

Use it alongside RTK, Headroom, native caching, or your own optimizer. Read the methodology ↗
