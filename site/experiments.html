01 · NO INSTALLATION

Open a usage report

Already have a TraceFrugal JSON report? Open it here to see your costs and token breakdown. The file is read in your browser and is never uploaded.

How do I make this report?

With recorded usage and your model prices:

tracefrugal report --trace run.jsonl --prices prices.json --format json > report.json

Export a report, not raw prompts or API credentials.

Want automatic optimization?

Connect a task evaluator and have your application read the managed settings. TraceFrugal tests a candidate, checks cost per successful task, and only applies it if the configured checks pass. The dashboard shows results and offers rollback. A browser report alone cannot change your application.
